# Projeto de estudo — HTML e CSS

Exercício de desenvolvimento web realizado no contexto de estudos na Fullture. Este repositório preserva uma etapa da minha trajetória de aprendizado em interfaces web.

## Conteúdo

- `index.html`: página inicial.
- `produtos.html`: apresentação de produtos.
- `faleconosco.html`: interface de contato.
- `css/`: estilos e organização visual.
- `font/` e `img/`: recursos utilizados na interface.

## Tecnologias

HTML e CSS. O repositório contém uma interface estática; não representa uma aplicação completa de comércio eletrônico.

## Visualização

Abra o arquivo `index.html` no navegador e navegue pelas páginas disponíveis.
